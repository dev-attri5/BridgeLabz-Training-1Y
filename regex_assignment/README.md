# Regex Assignment Project

This folder contains the complete solution set for `Submission of Regex.pdf`.

## Contents

- `src`: integrated runnable project for all regex problems
- `standalone`: separate Java files for each solved problem

## Coverage

- 15 regex problems covering validation, extraction, replacement, and pattern matching

## How to Run

```powershell
javac -d out src\*.java
java -cp out RegexAssignmentProject
```

## Notes

- Sample data is embedded in each solution so every program runs without interactive input.
- The PDF repeats some sections; this folder solves each unique problem once.
