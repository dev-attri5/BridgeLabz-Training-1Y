# Lambda Expressions Assignment Project

This folder contains the complete solution set for `Lambda Expressions Problem Statements.pdf`.

## Contents

- `src`: integrated runnable project for all lambda-expression and method-reference problems
- `standalone`: separate Java files for each solved problem

## Coverage

- 3 lambda-expression problems
- 3 method-reference problems

## How to Run

```powershell
javac -d out src\*.java
java -cp out LambdaExpressionsAssignmentProject
```

## Notes

- Sample data is embedded in each solution so every program runs without interactive input.
- The method-reference section includes examples of instance method references, static method-style usage in streams, and constructor references.
