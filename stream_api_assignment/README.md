# Stream API Assignment Project

This folder contains the complete solution set for `Stream API Problem Statements.pdf`.

## Contents

- `src`: integrated runnable project for all Stream API and `forEach()` problems
- `standalone`: separate Java files for each solved problem

## Coverage

- 5 Stream API problems
- 5 `forEach()` method problems

## How to Run

```powershell
javac -d out src\*.java
java -cp out StreamApiAssignmentProject
```

## Notes

- Sample data is embedded in each solution so every program runs without interactive input.
- The examples show filtering, sorting, grouping, mapping, and console-oriented `forEach()` use cases.
